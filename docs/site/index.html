macSubtitleOCR

Drop a Blu-ray rip, get clean .srt files.

A native macOS app that turns PGS and VobSub bitmap subtitles — from MKV, SUP, and SUB/IDX files — into accurate SubRip text using Apple's Vision OCR. Pick the tracks you want, then check every cue against the image it came from. Nothing else to install.

Why this exists

Bitmap subtitles are pictures of words. Turning them into text on a Mac has meant either a command-line tool that runs OCR over every track in a file, or a cross-platform editor that doesn't feel like a Mac app — and in both cases, no easy way to see whether the result is right.

macSubtitleOCR does the whole job in one place: see every track, pick the ones you want, recognize only those, and check the result against the original images before you mux. It reads Matroska itself, so there is nothing to install alongside it.

What it does

PGS & VobSub OCR

Reads Blu-ray PGS and DVD VobSub bitmap subtitles from .mkv, .mks, .sup, and .sub/.idx files.

Pick exactly what you want

Every track is listed with its language, name, and flags — English (SDH), Italian (Commentary), forced signs-and-songs. Tick as many as you like; matching languages are ticked for you.

Apple Vision accuracy

OCR runs through Apple's Vision framework — meaningfully better than Tesseract on small fonts, accents, and italic dialogue.

Clean SRT, sensibly named

Each track lands as MyFilm.eng.srt (or MyFilm.eng.english-sdh.srt) right next to the film — ready to mux. Send them somewhere else from the toolbar if you would rather.

See what it read

Every cue is shown beside the exact bitmap the recognizer saw. Cues it was unsure about are flagged. Fix any of them inline — the .srt updates as you type.

Nothing else to install

Matroska parsing, subtitle decoding, and recognition all happen inside the app. No Homebrew, no MKVToolNix, no helper binaries.

Batch a season

Drop a folder and every supported file joins the queue. Watch per-cue progress; cancel any time without losing what's finished.

Signed, notarized, universal

The published .dmg is Developer-ID signed, notarized by Apple, and runs natively on Apple silicon and Intel. Fully open source, MIT licensed.

How it works

Add, pick, make, review. No configuration required.

  1. Add files. Drag them onto the window, press ⌘O, use the Finder's Open With menu, or select files and choose Services ▸ Recognize Subtitles. Drop a folder to queue a whole season.
  2. Pick tracks. The queue across the top of the window expands each file into its PGS and VobSub tracks, with language, cue count, and what each one is doing. Tracks in your language are ticked automatically.
  3. Choose where they go. The toolbar says where the subtitle files will land. Next to the film is the default; pick a folder instead, or have the app ask each time.
  4. Make subtitles. Press the play button, or ⌘R. Progress counts real cues — "312 of 1,204" — and the same button becomes Stop, which never loses finished work.
  5. Review. Every cue appears beside its original bitmap, with low-confidence ones flagged. Correct anything that's wrong; the file is rewritten as you go.

Download & install

Two ways in. The signed .dmg is the easy path.

Option 1 — download the signed .dmg. Grab the latest release, mount it, drag the app to /Applications. It's signed with a Developer ID and notarized by Apple, so it opens with no Gatekeeper warning.

Option 2 — build from source:

$ git clone https://github.com/jeffalldridge/macSubtitleOCR-gui
$ cd macSubtitleOCR-gui
$ make app
$ open build/macSubtitleOCR-gui.app

Requirements: macOS 15 (Sequoia) or newer. Nothing else — the app has no runtime dependencies. Building from source needs Xcode 26.

FAQ

How do I convert PGS subtitles to SRT on a Mac?

Drop an MKV or SUP file onto macSubtitleOCR, tick the PGS track you want, and press Recognize. Apple's Vision framework reads the bitmap subtitles and writes a clean SRT next to your source file — ready to mux into an MP4 with Subler or your tool of choice. You can check every cue against its original image first.

Does it handle VobSub (.sub / .idx) subtitles?

Yes. It reads VobSub tracks from MKV files as well as standalone .sub/.idx pairs, and OCRs them to SRT the same way it handles Blu-ray PGS.

Is this a free Subtitle Edit alternative for macOS?

It's free and MIT-licensed. Subtitle Edit is a far broader editor — conversion, timing, the works. macSubtitleOCR is intentionally narrower: PGS / VobSub bitmap subtitles in, clean SRT out, with native Apple Vision OCR and a review pass. If you mostly need accurate bitmap-to-text on a Mac, this is purpose-built for that.

Why Apple Vision instead of Tesseract?

Apple's Vision framework consistently produces better OCR for bitmap subtitles than Tesseract — especially on the small letter-shape edge cases (l vs I, accented characters, italic dialogue). The upstream macSubtitleOCR project has benchmarks; Vision wins.

Does it work with .m2ts Blu-ray streams?

Not directly. Demux to .mkv first, or rip the disc with MakeMKV — both produce MKVs with the original PGS streams intact, which the app reads natively.

Can I run it on an Intel Mac?

Yes. The published .dmg is a universal binary and runs natively on both Apple silicon and Intel Macs, on macOS 15 or newer.

Do I need MKVToolNix or Homebrew?

No. Versions up to 0.2 called mkvmerge and mkvextract at runtime. Version 1.0 reads Matroska itself, so the app is entirely self-contained — download it and it works.

Is the recognized text always correct?

Not always, which is why the review screen exists. Every cue is shown beside the image it came from, and the ones Vision was least sure about are flagged so you know where to look. Italics, very small type, and decorative faces in musicals or animation are the usual trouble spots. On a Mac with Apple Intelligence you can also ask the on-device model to propose fixes for flagged cues — shown as before/after suggestions you accept or reject.

Does anything leave my Mac?

Only the once-a-day check for a newer release, which asks GitHub for the latest version number and nothing else. You can turn it off in Settings. Recognition, clean-up, and translation all run locally on your Mac.
