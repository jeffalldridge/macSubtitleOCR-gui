# Test fixtures

The `sintel.*` files come from the upstream
[macSubtitleOCR](https://github.com/ecdye/macSubtitleOCR) test corpus
(MIT License, © Ethan Dye). They contain a short excerpt of the open movie
*Sintel* (© Blender Foundation, CC BY 3.0) as PGS (`.sup`), VobSub
(`.sub`/`.idx`), and a Matroska container (`.mks`) holding both tracks,
plus the reference SRT and Vision JSON output.
